# ☕ Coffe point - Landing Page (En desarrollo)

Este es mi proyecto de practica personal donde combino  el **Diseño de Interfaces (UI)** y la **Maquetacion Web Frontend**. Busco crear una experiencia digital visualmente calida, limpia y moderna para una cafeteria de especialidad.

## 🛠️ Tecnologias y conceptos que estoy usando:
- **HTML5** Estructura semantica clara para los textos y secciones.
- **CSS3:** Estilos, tipografias modernas y diseño de botones de accion (*View Menu* y *Book Table*).
- **Enfoque UI:** Cuidado minucioso en los margenes, espaciados y la paleta de colores para lograr una armonia visual.

## 📍 Estado actual:
El proyecto se encuentra **en desarrollo activo**. Voy avanzando a mi propio ritmo, enfocandome primero en la estetica y la alineacion de los elementos queden perfectas antes de sumar interactividad.
